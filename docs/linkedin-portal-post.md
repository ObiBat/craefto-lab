Built something I wish existed when I started freelancing.

Most agencies send PDF reports. Clients wait days for updates. Everyone's guessing what's happening.

So I built a real-time stakeholder portal for my studio.

Clients log in to their own subdomain. They see every decision, every blocker, every milestone as it happens. Rich text updates, file attachments, activity sparklines, horizontal timelines.

The stack: Next.js 16, Supabase (auth + realtime + RLS), TipTap for rich text, Framer Motion for polish. Deployed on Vercel with subdomain routing.

Built it in 2 weeks across 5 sprints. Already using it with clients.

The pitch writes itself: "We don't just build and disappear. You get a live portal."

Transparency shouldn't be a premium feature. It should be the baseline.

Live at project-portal.craefto.com
