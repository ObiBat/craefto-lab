## Content Flywheel

### The Compounding Loop
1. **Publish** → Article goes live
2. **Index** → Google picks it up (2-4 weeks)
3. **Rank** → Starts appearing for keywords
4. **Traffic** → Visitors discover Craefto
5. **Convert** → Some become leads
6. **Learn** → Analytics show what works
7. **Repeat** → Double down on winners

### Content Pillars (tied to services)
1. **Design Engineering** → Web/Product clients
2. **Brand Systems** → Brand clients
3. **AI/Automation** → AI clients
4. **Security** → Security clients
5. **Founder Resources** → All ICPs

### Publishing Cadence
- **2 articles/week** (Tue + Thu)
- **1 case study/month** (after project completion)
- **Daily social** (repurpose article snippets)

## Productized Services

### Current Problem
- Every project is custom scoped
- Pricing discussions slow deals
- Scope creep risk high
- Hard to scale

### Solution: Fixed Packages

#### 1. Brand Sprint (2 weeks | $5,000)
- Logo + wordmark
- Color system
- Typography system
- Brand guidelines PDF
- Social templates

#### 2. Launch Site (3 weeks | $8,000)
- 5-page marketing site
- Responsive design
- Basic SEO setup
- Contact form + CRM integration
- 1 round of revisions

#### 3. MVP Build (6 weeks | $25,000)
- Core feature set (defined upfront)
- Auth + database
- Admin dashboard
- Deployment + docs
- 2 weeks post-launch support

#### 4. Security Audit (1 week | $3,000)
- Web app pen test
- Vulnerability report
- Executive summary
- 30-day re-test included

#### 5. AI Integration (3 weeks | $10,000)
- 1 defined automation/agent
- Integration with existing tools
- Documentation + training
- 30-day support

### Custom Projects
For anything outside packages: Discovery call → Custom proposal
