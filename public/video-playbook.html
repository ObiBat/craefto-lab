The CRAEFTO AI Marketing Video Playbook

A complete production system for the most advanced AI marketing video CRAEFTO can ship in 2026 — strategy, stack, prompt grammar, and a fully-prompted first brand film. Built for the studio, ready to productize for clients.

Owner · Founder Stack · SaaS-only, ~$430–580/mo Cadence · Weekly Friday block Status · Ready to execute

01Overview

Why this playbook exists, and what it gives you.

CRAEFTO's marketing engine today is a written-content flywheel: the 5-stage Gemini/OpenAI agent pipeline pushes ~2 journal articles per week, plus a Next.js 16 site running the Paper & Ink design system, plus a project portal. There is no video production capability — and the Video Editor role on the careers page is still vacant.

This playbook layers professional AI-generated video on top of that flywheel. By May 2026, the AI video stack — Veo 3.1, Runway Gen-4, HeyGen, ElevenLabs, Descript, OpusClip, Suno — is finally good enough to ship agency-grade video without a film crew, for under $600/month. World-class brands (Coca-Cola, Mango, Toys "R" Us, Heinz, Nike, FIS) are already doing it. This is CRAEFTO's version.

What you get A SaaS-only stack, four production workflows (brand film, service explainer, social short, founder talking head), brand-fit guardrails, a 4-week rollout, a fully-prompted 75-second brand film as the first deliverable, and a productization path so the same machine sells to clients later.
What's out of scope Code changes in craefto-lab, building a custom video studio UI under /lab, integrating with the existing 5-stage agent pipeline, Synthesia, Sora, Kling, self-hosting open-source video models. All deferred.

03Workflows by format

Four formats, each with its own production loop. Cadence stacks against the existing journal flywheel.

Brand films · 60–90s hero · 1 per quarter

  1. Script — reuse the existing Editorial Strategist + Editor Guardian agents to draft and polish the voiceover (no code change; just feed them a brand-film prompt template).
  2. Storyboard / shot list — 8–12 shots, each with a reference still in Paper & Ink palette. Generate stills in Midjourney or Flux.
  3. Shots — Runway Gen-4 with reference stills for consistent shots; Veo 3.1 for the 2–3 cinematic hero shots that need native ambient audio.
  4. VO — ElevenLabs founder voice clone reading the script.
  5. Music — Suno custom track ("warm acoustic, restrained, atelier feel, sage-green emotional palette").
  6. Assembly — Descript timeline; export 16:9 master + 1:1 LinkedIn cut + 9:16 social cut.
  7. Destination — hero slot on craefto.com, pitch decks, sales-call follow-up emails (Resend).

Service explainers & case study walkthroughs · 60–180s · recurring

  1. Founder records screen + voice in Descript — live, no script needed, speak from a 5-bullet outline.
  2. Descript transcribes → founder deletes filler words and rambling sections from the transcript (cuts apply automatically).
  3. HeyGen Avatar IV intro card (5s): "I'm [Founder], here's how we shipped X for Y."
  4. Insert 2–3 Runway b-roll cuts where the screen recording is visually flat.
  5. Captions via Descript or OpusClip.
  6. Destination — /services/<slug>, /journal/<slug> case-study posts, project portal.

Social shorts · TikTok / Reels / LinkedIn · 15–45s · 2–4/week

  1. Source: pipe each new long-form asset through OpusClip Pro. Auto-extracts 5–10 hook-driven clips with captions, 9:16 reframed.
  2. Operator picks 2–3 winners per source, tweaks hook copy.
  3. Post directly from OpusClip's scheduler (or Buffer) to LinkedIn, TikTok, X, Instagram, YouTube Shorts.
  4. Cadence aligns 1:1 with the existing 2-articles/week content engine — every article ships with at least one short.

Founder talking head · thought leadership · 1–2/week

  1. Source script = the TL;DR of each new journal article (already drafted by Editor Guardian — no extra writing).
  2. HeyGen Avatar IV with founder's cloned face + ElevenLabs voice clone reads it.
  3. Auto-translate into 2–3 priority languages (EN-AU, EN-US, ID for SEA market) — HeyGen preserves lip-sync.
  4. Repurpose through OpusClip into 2–3 micro-clips per source.
  5. Destination — embedded at top of each journal article; LinkedIn/X with article link; nurture sequences.

04Brand-fit guardrails

Paper & Ink in motion. These prevent generic AI gloss — the #1 reason AI video reads as cheap.

Color

Lock HeyGen brand kit + Runway style references using the exact tokens from the design system: cream #FAF7F2, deep ink #1A1714, sage #4B6B57. Reject anything drifting to neon, teal, purple.

Texture

Prompt for paper grain, ink wash, hand-letterpress motifs, restrained motion. Avoid lens flares, particles, "epic" camera moves.

Pacing

Slow cuts (1.5–3s) for brand films. Snappy cuts (0.4–0.8s) for social. Never the AI-default 1s metronome.

Voice direction

ElevenLabs voice clone — stability ~0.45, similarity ~0.78. Conversational authority, not radio-DJ.

Music

Suno prompts: "acoustic, atelier, restrained, no drop, no EDM". Lean folk and ambient.

Avatar

HeyGen Avatar IV trained on ≥5 minutes of founder footage in good light, neutral background. Re-record if the result has the AI-plastic tell.

Captions

Single line, sage-on-cream, sentence case. Reject the OpusClip default ALL CAPS YELLOW.

Faces

If a face appears, it must read as on-brand. No stock-photo smiles, no AI-uncanny eyes, no thumbs-ups to camera.

08Trending formats for CRAEFTO

Of the ten 2026 formats going viral, the five that fit a B2B creative-tech studio.

1 · Cinematic origin / brand anthem

The hero film. One per quarter. Highest production value, lowest volume. Anchors the home page and pitch deck.

2 · UGC-style founder talking head

HeyGen Avatar IV on weekly journal pairing. Replaces "thought leadership posts" as the unit of social currency.

3 · Faceless POV storytelling

First-person hands at keyboard / wireframe / shipped product. Excellent for case studies. Zero on-camera talent needed.

4 · Process tier-rank

"Ranking the 10 SaaS landing pages we audited this month, S to F." High CTR. Fits security-audit positioning.

5 · AI vubbing (visual dubbing)

Translate top-performing journal videos into ID/ES/JP for SEA/global reach. HeyGen handles natively with lip-sync.

Hook archetypes that own the first 3 seconds

63% of high-CTR videos hook viewers immediately. The four archetypes that win:

  • Pattern interrupt + curiosity gap — visually unexpected opener + an unanswered question.
  • Pain-point declaration — name the audience's problem in the first 1.5s.
  • Receipts hook — open on a numeric proof point ("$2.3M of pipeline this changed…").
  • Insider POV — "Inside the studio that ships software like a brand."

The brand film below uses insider POV + pattern interrupt — opens on a letterpress, then immediately cuts to code on the same press's paper, breaking the design-vs-engineering frame in 4 seconds.

09Prompt grammars

Two engines, two grammars. Learn both and you can make anything.

Veo 3.1 — Google's official 5-part formula

[Cinematography] + [Subject] + [Action] + [Context] + [Style & Ambiance]
  • Cinematography — shot type, camera move, lens. e.g. "Slow dolly-in, 35mm, shallow depth of field"
  • Subject — the focal element, described concretely.
  • Action — what happens, with physics ("hands gently lift the metal type").
  • Context — environment, props, time of day.
  • Style & ambiance — mood, color, grain, era, lighting source.

Length: 3–6 sentences, 100–150 words per shot is the sweet spot.

Audio syntax — Veo 3.1's killer feature

A woman says, "We have to leave now."
SFX: thunder cracks in the distance
Ambient noise: the quiet hum of a starship bridge

Negative prompts

Describe what should be absent positively. Say "a desolate landscape with no buildings" not "no buildings".

Multi-shot sequences with timestamps

[00:00–00:02] Medium shot of … [00:02–00:04] Reverse shot of … [00:04–00:06] Tracking shot following …

Runway Gen-4 — reference-driven, not text-driven

Upload 1–6 reference images. Tag them in the prompt as image_1, image_2, … One reference image carries character/brand consistency across an entire campaign (40% better fidelity than Gen-3). Do not write conversational prose — Runway penalises it. Write declarative visual detail.

Using image_1 (the founder), image_2 (the studio environment), and image_3 (the Paper & Ink color palette), create a slow tracking shot of the founder walking through the studio, hand brushing a paper sample on the wall, 4-second clip, soft window light from the left.
When to use which Use Veo 3.1 when you need synced audio, cinematic motion, or shots nothing in your reference library covers. Use Runway Gen-4 when you need the same character/space across many shots, or you need to ground a generation in a specific real photo.

Per-shot prompts

Shot 01 — Hands at letterpress · Veo 3.1

Slow dolly-in, 50mm lens, shallow depth of field. A craftsman's hands, warm light tan skin, gently lift a single piece of metal type from a wooden compositor's tray and place it into a forme. The studio is dim, lit by a single warm window from camera-left at 4 PM, dust motes visible in the beam. Cream paper (#FAF7F2), brass type, deep ink-black shadows, sage-green felt lining the tray. Photorealistic, 35mm film grain, restrained warmth, atelier mood. SFX: a soft metallic click as the type seats; faint distant traffic; ambient noise of an empty workshop at late afternoon. Negative: no neon, no shiny chrome, no lens flare, no people's faces.

Shot 02 — Code on the same paper · Veo 3.1

Continuation of the previous scene, same lighting and lens. Macro close-up. The same letterpress press now slowly stamps a sheet of cream paper (#FAF7F2), but the impression that lands is not a logo — it is three lines of monospaced code in deep ink black: the JSX of a React component. The press lifts, paper rests, ink glistens for a half-second before settling matte. Camera holds, then a 2-degree push on the page. SFX: the heavy mechanical thunk of the press; the slow exhale of a spring; a single soft typewriter-like tick at the moment the press lands. Style: 35mm film grain, warm cream / deep ink, sage felt visible at the edge of frame. Negative: no glowing screens, no holograms, no digital effects.

Shot 03 — Code dissolves into UI · Runway Gen-4

Using image_3 (Paper & Ink palette: cream #FAF7F2, ink #1A1714, sage #4B6B57) and image_4 (CRAEFTO wordmark) as the only color and brand reference. Macro shot of the same printed page from the previous beat. The printed code lines slowly dissolve into a clean dashboard UI in the same color palette — a real-looking SaaS analytics interface, typeset in a serif/sans pairing, no fake-looking Latin placeholder text. The page texture remains visible underneath the UI, as if the interface were printed onto paper. 4 seconds, no camera move, slow crossfade transition. Negative: no glow, no neon, no animated cursors, no generic dashboard purple/blue.

Shot 04 — Studio wide · Runway Gen-4

Using image_2 (the CRAEFTO studio reference) and image_3 (Paper & Ink palette). Wide static shot of the studio interior at late afternoon: sage-green wall on the left, cream paper samples pinned in a 3×3 grid, two long oak desks, soft north-facing window light, no overhead fluorescents. Two figures faintly visible in deep background, out of focus, working. 5-second hold, no camera move. Photorealistic, 35mm film stock, warm grain, archival mood. Negative: no studio cliches (no neon signs, no exposed Edison bulbs, no plant walls), no people in sharp focus.

Shot 05 — Founder on call · Veo 3.1

Medium close-up, 35mm, eye-level, very shallow depth of field. The founder (mid-30s, see image_1) sits at a cream-paper-covered desk in the same sage-walled studio, headset on, looking down at a sketch. He's mid-conversation, calm, leaning slightly forward. Soft window light from the left. The founder says quietly, "Then we ship it Friday. Whole thing — brand, build, audit." Naturalistic delivery, no sales-y inflection. Ambient noise: faint mechanical keyboard tap from a colleague off-screen, a kettle just clicking off in the distance. Style: photorealistic, 35mm grain, warm cream, restrained. Negative: no exaggerated facial expressions, no fast cuts, no music swell yet.

Style: 35mm film grain, near-silent, atelier reverence, warm restrained light. Negative: no metallic sparkle, no rainbow foil, no glow.

No animation other than a 1-degree breathing motion as if the paper is gently held. Hold for 8 seconds. SFX: ambient room tone, the very faint distant sound of a press mechanism returning to rest. Style: 35mm grain, atelier silence, deep ink shadow inside each letter.

Shot 12 — End card · Static, composed in Descript

Hold the previous shot. Layer two text lines: Top line · deep ink (#1A1714) · sentence case · "Craft means it works." Bottom · sage (#4B6B57) · monospace · "craefto.com" Hold 7 seconds. Fade to cream over the final 1.2s.

Music · Suno prompt

Style: minimal acoustic atelier score. Single nylon-string guitar arpeggio in Em7 → Cmaj7 → G → Dsus4. Sparse upright piano joins at 0:30. Soft brushed snare enters at 0:50. No drop, no EDM, no synthetic strings, no swells over +3dB. Texture: warm, restrained, folk-ambient, slightly tape-saturated. Length: 1:18. Final 4 seconds: all instruments soften, leaving only the nylon guitar resolving on a sustained Em7. Mood: quiet confidence, craftsperson at work. Lyrics: instrumental, no vocals.

Generate 4 variants in Suno Pro. Pick the one whose chord changes align with the cuts at 0:08, 0:24, 0:50, 1:00.

Voiceover · ElevenLabs settings

Voice & model

Voice: founder voice clone (Instant Voice Clone, trained on 30+ minutes of clean speech).
Model: Eleven Multilingual v3 (best for nuanced English-AU).

Parameters

Stability: 0.42 (allows natural inflection).
Similarity: 0.78 (preserves founder timbre).
Style exaggeration: 0.15 (low — conversational, not performance).
Speaker boost: on.

Render each line as a separate clip for easy timing in Descript.

Captions · Descript / OpusClip settings

  • Style: single line, sentence case (NOT all caps).
  • Color: deep ink #1A1714 text on a 60%-opacity cream #FAF7F2 rounded pill.
  • Position: bottom 22% of the frame, centered.
  • Font: same sans you use on craefto.com.
  • Highlight color (active word): sage #4B6B57.
  • Reject OpusClip's defaults: yellow caps, animated word-pop, emoji insertion.

11Step-by-step execution · one working day

Six hours, top to bottom. Assumes accounts and references are ready.

Hour 0 · Pre-flight (30 min)

  1. Confirm logins for HeyGen Team, Runway Pro, Google AI Studio (Veo 3.1), ElevenLabs Creator+, Descript Pro, OpusClip Pro, Suno Pro.
  2. Prepare the four reference images:
    • image_1 · founder portrait, neutral background, soft daylight, 1024×1024.
    • image_2 · wide photo of your actual studio (or a curated dribbble pin in your aesthetic), 1920×1080.
    • image_3 · flat 3-swatch image with the exact hex values labelled.
    • image_4 · CRAEFTO wordmark, transparent PNG, 2048px wide.
  3. Confirm founder voice clone is trained in ElevenLabs and tested with the script lines.

Hour 1 · Generate Veo 3.1 shots (60 min)

For each Veo shot (01, 02, 05, 07, 09, 11):

  1. Open Google AI Studio → Veo 3.1.
  2. Paste the prompt verbatim from §10.
  3. Set: 4K, 16:9, 24fps, duration matches the shot list.
  4. Generate 3 variants per shot — Veo 3.1 has high variance; selecting from 3 is the established practice.
  5. Download the best of three. Name files shot-01_v1.mp4, etc.
  6. If a shot fails twice (wrong style, AI gloss, dialogue mismatch): tighten the negative prompt and re-run. Do not "prompt engineer harder" — restructure the 5-part formula.

Hour 2 · Generate Runway Gen-4 shots (60 min)

For each Runway shot (03, 04, 06, 08, 10):

  1. Open Runway → Gen-4 References.
  2. Upload all four reference images, label them image_1 through image_4.
  3. Paste the prompt verbatim from §10.
  4. Set: 4K, 16:9, duration per shot list.
  5. Generate 2 variants per shot. Download best of two.

Hour 3 · Voice + music (45 min)

  1. ElevenLabs: paste each voiceover line from §10 into the cloned voice with §10 settings. Render each line as its own MP3.
  2. Suno: paste the music prompt. Generate 4 variants. Pick the one whose chord transitions feel native to your cut points. Download as WAV.

Hour 4 · Assemble in Descript (90 min)

  1. New Descript project, 1920×1080, 24fps.
  2. Drag all 11 video shots in order, snap to the timestamps in the shot list.
  3. Import voiceover clips, place each on the timestamp from the script.
  4. Import the Suno track, lay under the entire timeline at -18 LUFS bed, ducking under voiceover by -6dB automatically.
  5. Use Descript's transcript editor to nudge any phrase that runs long.
  6. Add captions per §10 spec.
  7. Add Shot 12 end card as a frame composition.
  8. Render: 4K H.264 master, 16:9. Save as craefto-brand-film-v1.mp4.

Hour 5 · Repurpose with OpusClip (30 min)

  1. Upload the 4K master to OpusClip Pro.
  2. Run "AI Highlights" — auto-extracts 6–10 short clips with hooks.
  3. Generate two manual cuts of your own:
    • 9:16 LinkedIn cut: 28 seconds, opens on shot 02 (the pattern interrupt), ends on shot 11 + end card.
    • 1:1 X / IG cut: 45 seconds, full arc compressed.
  4. Apply the §10 caption style across all cuts. Re-style if OpusClip ignores the brand kit (it sometimes does on first try — re-apply).
  5. Export all cuts at 4K H.264.

Hour 6 · Ship (30 min)

  1. Home page: replace current hero with the 16:9 master. Use a poster frame from shot 11 (wordmark on cream).
  2. LinkedIn: post the 28-second 9:16 cut. Caption opens with: "Most studios pick a side. We never bought that."
  3. X: post the 45-second 1:1 cut. Same opening line.
  4. Sales follow-up email (Resend): embed a thumbnail-with-play-button link to the 4K master, hosted on Vercel.
  5. Pitch deck: drop the 16:9 master into slide 1.
  6. Project portal: place under "About CRAEFTO".

12Quality gates · 15-minute audit before publishing

Reject and re-shoot any shot that fails ANY of these.

  • AI-gloss test — does any shot have the plastic AI look (over-smooth skin, perfectly symmetrical face, glassy reflections)? If yes, re-generate with more film-grain language.
  • Palette drift — does any shot drift to teal/purple/orange? If yes, tighten negative prompts.
  • Cut rhythm — are brand-film cuts ≥1.5s? Snappier cuts read as social, not brand.
  • Audio sync — is every voiceover line locked to its visual beat? Drift >120ms is noticeable.
  • Caption legibility — captions readable at 320px wide (mobile feed)?
  • Brand-mark accuracy — does the wordmark in shots 07 and 11 actually spell CRAEFTO correctly? AI commonly misspells brand marks; this is mandatory to verify.
  • Faces — if any face appears, is it on-brand? No stock-photo smiles, no AI-uncanny eyes.
  • CTA on end card — does craefto.com resolve in a browser test?
  • No watermarks — Runway and Veo can stamp watermarks on free tier; verify Pro export.
  • Sound check — listen on phone speakers AND headphones. Voiceover at -16 LUFS, music bed at -22 LUFS.

If 8 / 10 pass, ship. If <8, identify the failed gate and re-run only the affected shot.

16Production pipeline

How a single shot is actually made — and how to choose between still-first, direct text-to-video, and live capture.

Pros don't write one prompt and hit render. Every shot belongs to one of three production paths. Knowing which to use is what separates "I generated a video" from "I directed a film". The whole 75-second brand film in §10 mixes all three.

The 11-step flow for any single piece

  1. Concept — logline + 1-paragraph treatment.
  2. Script — voiceover timed to seconds, locked at 110 wpm.
  3. Shot list — 8–12 shots, each with tool + intent + length.
  4. Reference — pull mood references (Aesop films, Apple Newsroom, Loewe campaigns, Vimeo Staff Picks). Save to a Pinterest board per project.
  5. Stills — generate reference stills in Midjourney v7 or Flux Pro for shots that need locked composition. Iterate 10–30 stills, pick 1–3 winners.
  6. Animation — bring those stills to life via Runway Gen-4 image-to-video, OR generate the shot direct in Veo 3.1 if you need synced audio.
  7. Live capture — Descript screen recording for any real UI, real Figma, real terminal.
  8. Voice — ElevenLabs cloned founder, line-by-line.
  9. Music — Suno custom score, generated to length.
  10. Assembly — Descript timeline; caption pass; light color grade in Descript.
  11. Export & ship — 16:9 master + 9:16 + 1:1 cuts. Schedule, post, monitor.

The three production paths

Path A · Still-first → animate

Generate a reference still in Midjourney or Flux Pro until composition, color, and texture are exactly right. Then bring it to life in Runway Gen-4 (image-to-video) with a short motion direction.

Why: stills cost ~$0.04 each vs $3–15 for a video gen. You can iterate 30 stills before committing to 3 animations. Stills also let you lock frame composition before motion is applied — which is the difference between "AI video" and "directed film".

When: any shot where frame composition matters more than physics. Brand films, hero shots, beauty shots, atmospheric POV, the 80% case for editorial work.

Path B · Direct text-to-video (Veo 3.1)

Skip the still. Write the full Veo 3.1 prompt — including SFX, ambient, and dialogue — and render the video + audio in one pass.

Why: Veo 3.1 is the only mainstream model that generates video + synced audio together. The audio quality is professional-grade and saves a separate Foley/voiceover step.

When: talking-head with dialogue. Action shots (a press lever pulling, water drops landing on paper). Anything ≤4s with strong physical motion that's hard to fake from a still.

Path C · Live capture

Descript screen recording of the actual UI, Figma, terminal, or real handwriting. No AI involved.

Why: AI models can't render specific brand UIs accurately enough for B2B trust. Real screen capture is faster, more honest, and reads as evidence.

When: service explainers, case studies, code editors, anything showing real software. Always pair with a Path A or Path B opener for cinematic value.

Path D · Composition (Descript)

Static cards, text overlays, end frames, annotations on top of other footage. Built directly in Descript with shape tools and text layers.

Why: precise type, precise timing, full control. AI can't do this reliably.

When: end cards, title cards, captions, annotation overlays, tier-list grids, split-screen compositions.

Editorial style markers · CRAEFTO

What separates editorial AI video (Aesop, Loewe, Apple, Bottega) from generic AI marketing slop. Every shot in every idea below should pass this checklist:

  1. Negative space is a character. Let cream paper breathe. Subjects should occupy 30–55% of frame, not 80%.
  2. Single light source. One warm window from camera-left at a known time of day. Never flat overhead.
  3. Restrained motion. ≤2-degree dollies, 1.5–3s holds. No whip-pans, crane reveals, or rotating cameras.
  4. Texture obsession. Paper grain, ink wash, brass type, sage felt. If you can't see grain, the shot is too clean.
  5. Eye-line composition. Frame for emotional center, not a "cool angle".
  6. Color discipline. Cream / ink / sage only. Anything else gets re-prompted with a tighter negative.
  7. One verb per shot. Tap. Lift. Press. Breathe. Multiple verbs = multiple shots.
  8. Sound restraint. Silence between sounds matters. Veo prompts should specify quiet first, sound second.
  9. Type as photography. Wordmarks letterpressed and shot like still life — not animated logos.
  10. No visible interface. UI shown only when narratively required. No fake cursors flying.

Worked example · Shot 01 of the brand film, three ways

Same shot ("hands at letterpress lifting metal type"), three approaches:

Path A — Still-first

extreme macro photograph, craftsman's hands lifting a single piece of brass type from a wooden compositor's tray, cream cotton paper #FAF7F2 underneath, sage felt lining the tray, single warm window light from left at 4pm, dust motes in the beam, 50mm lens, shallow depth of field, 35mm film grain, atelier mood, no faces, restrained, --ar 16:9 --style raw --v 7
Using the still as the first frame: hands gently lift the brass type and place it into a forme to the right of frame. Slow 1-degree dolly-in over 4 seconds. Real-world hand speed; no slow-motion. End frame: type seated in forme. Aspect 16:9.

Cost: ~$0.04 still + ~$3 video = ~$3.04. Time: 8 minutes including iteration. Audio: must be added separately in Descript.

Path B — Direct Veo 3.1

Slow dolly-in, 50mm lens, shallow depth of field. A craftsman's hands gently lift a single piece of metal type from a wooden compositor's tray and place it into a forme. Studio is dim, lit by a single warm window from camera-left at 4 PM, dust motes visible. Cream paper #FAF7F2, brass type, deep ink-black shadows, sage-green felt lining the tray. Photorealistic, 35mm film grain, restrained warmth, atelier mood. SFX: a soft metallic click as the type seats; faint distant traffic; ambient noise of an empty workshop at late afternoon. Negative: no neon, no shiny chrome, no lens flare, no people's faces.

Cost: ~$8–15. Time: 4 minutes (3 variants). Audio: included, professional grade.

The choice

For this shot, Path B (Veo 3.1) wins — the metallic click of the type seating is narratively important and a still-first path would require Foley work to match it. For Shot 03 of the same film (dashboard UI dissolve), Path A (still-first) wins — composition matters more than audio, and Runway Gen-4's reference handling is better than Veo 3.1's.

The default mix for a CRAEFTO 60–90s film ~50% Path A (still-first via Midjourney → Runway Gen-4) for editorial atmosphere · ~30% Path B (Veo 3.1 direct) for synced-audio hero shots · ~15% Path C (Descript live capture) for real UI · ~5% Path D (composition) for end cards. Adjust per idea — the per-shot tool column in each Idea Explorer card tells you which path is recommended.

AI gloss vs editorial AI · the difference at a glance

What separates Aesop / Loewe / Apple-grade AI video from generic AI marketing slop. The left column is what every default Veo 3.1 / Runway prompt produces unless you fight it. The right is what world-class brands ship — and what every CRAEFTO output should match.

Avoid · AI gloss tells

  • Over-smooth skin, plastic specularity
  • Glassy reflective surfaces everywhere
  • 1-second metronome cut rhythm
  • Saturated hyper-color, neon highlights
  • Flat overhead key light
  • Generic stock-photo smiles, AI-uncanny eyes
  • Floating cursors, glowing UI elements
  • Whip-pans, dramatic crane reveals
  • Symmetrical perfect faces
  • Bouncy easing curves on motion

Aim for · editorial markers

  • Visible 35mm film grain
  • Matte surfaces, paper texture obsession
  • 1.5–3-second considered cuts
  • Restrained palette — 3 hex codes maximum
  • Single warm window source, camera-left
  • Real, subtle micro-expressions or no faces
  • Real hand interactions, never floating
  • ≤2-degree dollies, eye-line composition
  • Imperfect — slight asymmetry reads as real
  • Real-world hand speed, no slow-motion default

Eight practices that produce world-class output

The discipline behind every Aesop, Loewe, and Apple-grade AI campaign. Adopt these as non-negotiable for any CRAEFTO production — internal or client.

01
Pull references first

Build a 30-image Pinterest board before writing a prompt. Aesop, Loewe, Apple, Eames. Don't generate without a target.

02
Iterate stills 20+ times

Stills are ~$0.04 each in Midjourney. Iterate until the frame looks photographed, not generated. Then animate.

03
Lock the brand kit

HeyGen brand kit + Runway style refs + Midjourney --sref all locked to the exact Paper & Ink palette. Reject anything that drifts.

04
Run the AI gloss test

For every shot, ask: would this pass a Vimeo Staff Picks editor? If skin is too smooth or surfaces too glassy, re-prompt with more grain language.

05
Slow down — 2.5s is the new 1s

Default AI cut rhythm is one cut per second. World-class is 1.5–3s holds. Brand films can hold a single shot for 8 seconds.

06
Single warm window light

Every prompt names one motivated light source — usually a window from camera-left. Never overhead fluorescents. Never flat.

07
Real audio over synthesized SFX

Veo 3.1's strength is native audio. For Path A shots, use real Foley or capture real sound. Synthesized SFX gives the AI tell instantly.

08
Restrict color to 3 hex codes

Cream #FAF7F2, ink #1A1714, sage #4B6B57. Anything else (teal, purple, neon) gets re-prompted with tighter negatives.
